## Intended use (decide before starting)

> There is **no "unknown" option**: if the user does not answer or answers vaguely, treat it as **commercial + closed source** (the strictest reading, see SKILL.md §7).
> When in doubt start commercial-closed and relax later — the other direction leaves copyleft code in the tree, which is expensive to remove afterwards.

| Use | Meaning |
|---|---|
| Personal | Only you use it; nothing is distributed |
| Free closed-source distribution | Others run it, no source, no fee |
| Open source (same license) | Source published under a compatible license |
| Commercial (paid / internal) | You earn money with it, or it runs inside a company process |

Default: **unknown = commercial + closed source** (GPL / AGPL / LGPL must not enter, see the note in SKILL.md §7).
